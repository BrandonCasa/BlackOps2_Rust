# Project state

The active task is a user-authorized replacement of costly custom lighting and shadows with Bevy's built-in raster renderer. The uncommitted sun-PCSS change was discarded before implementation. Runtime ray tracing, DDGI, traced reflections, custom shadow scheduling and all vendored engine copies are removed. Native cascaded sun shadows, a bounded set of shadowed point lights, atmosphere environment lighting, SSAO and distance fog form the replacement. Registry-only optimized-development compilation and the final full actual-game combat/ADS/Round 2/17-view/restart run pass. The development combat survey averages 19.3778 FPS with exactly eight active point shadows; this is not a matched release gain. Static full-LTO release and the 4137-file package pass. Three guarded six-actor 1080p release combat runs pass: 23.6339 FPS median, 23.2494-33.6792 FPS range and 78.5282ms median p95. No matched prechange release comparison exists; the variance remains material.

The current application remains one Rust/Bevy executable with Avian physics. Prepared Origins geometry/materials and gameplay assets are unchanged. Existing playable systems include movement, zombies/rounds, weapons/ADS/reload/melee, wall buys, equipment, perks, native animation/audio and restart. The atomic [gameplay checklist](../todo.md) remains the feature ledger; this renderer change does not complete its missing gameplay systems. Existing actor geometry defects remain a separate issue.

See the [current handoff](handoffs/current.md), [rendering contract](reverse_engineering/rendering.md), [architecture](architecture/README.md) and [asset rules](reverse_engineering/assets.md). The former renderer and lantern optimization plans are retired; Git history retains them. All work is sequential, with one shared actual-game validation slot. Unit tests, fixtures, Clippy and repository skills remain prohibited.
