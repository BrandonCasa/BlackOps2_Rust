# Standard rendering

The game loads the complete world and all placed static models through standard glTF. Bevy owns lifecycle, PBR, lights, shadows, bounds, culling, cameras, image filtering and post-processing. Original shaders, capture-selected geometry, frozen cameras and retired renderers are not production inputs. Tangents/handedness, RGBA vertex colors, UV seams and secondary world UVs survive preparation; shadow-helper geometry has collision disposition without visible walls.

## Opaque surface material

`src/rendering/opaque.rs` binds retained material/lighting data to `ExtendedMaterial<StandardMaterial, OpaqueSurface>`. Fresh project-owned `opaque.wgsl` is embedded in the executable, so relocating the standard runtime pack needs no extra shader file. Identity, readable family, ordered channel roles and `surface.preparation` select the response. Only lit opaque surfaces qualify; masked/blended/unlit/water/effect materials and hidden collision copies retain their existing dispositions. Layered opaque surfaces receive this response using their currently selected first layer; general terrain blending remains separate work.

Raw normal RG is sampled as data, evaluated as tangent-plane slopes using the researched `4.015748 * sample - 2.015748` convention, and transformed through Bevy's tangent frame. Source DirectX Y is reversed consistently with prepared tangent handedness. No softened runtime image copies remain. Default slope strength is one; the tile/macro family uses 0.5 because repeating detail at fourfold scale has a different response. Missing normal bindings use zero slope.

Raw specular RGB/gloss alpha is retained and sampled in linear data space. Gloss drives perceptual roughness through `sqrt(1 - gloss)`. Squared source RGB drives dielectric F0 with a 0.16 scale; Bevy receives the corresponding reflectance vector and handles direct-light BRDF/shadow response. Missing specular uses RGB 0.5/gloss 0.36, yielding F0 0.04/roughness 0.8. These explicit calibration parameters are tunable reconstruction choices, not recovered native constants. No concrete-name roughness rule or fixed per-surface reflectance assignment remains; metal-like source response is approximated as a tinted dielectric rather than inferred metallicity from names.

For `tile_macro_bake`, the existing sRGB diffuse bake is sampled once by Bevy. The raw macro red/green mask only combines layer-one/layer-zero normal slopes and specular/gloss samples at the preparation metadata's fourfold detail scale. We normalize those weights for material response; the diffuse bake already retains their occlusion magnitude. We neither blend the diffuse layers a second time nor treat the control image as albedo. Other retained layers stay in the pack for later work.

## Baked light and reflections

Opaque world lightmaps are sampled directly as linear packed data: the first two atlas bands decode RGB/alpha ambient A and directional D; the third decodes a source-basis direction L. Irradiance is `A + D * clamp(dot(L, mapped_normal), 0, 1)`. Band-local texel insets avoid cross-band bilinear bleeding. Floating-point shader evaluation retains HDR values above the previous clipped range of four. Primary atlases remain retained; this milestone uses the secondary packed layout established by the selected opaque research.

Static models use the retained LOD0 instance-color mean as linear irradiance when available, otherwise the assigned probe's source-basis SH polynomial. Means preserve instance assignment but lose within-model lighting gradients; sharing geometry is intentional. An added zero-valued secondary UV attribute on providers without one permits a zero Bevy Lightmap marker, which tells Bevy to exclude baked sunlight/ambient diffuse. The custom fragment supplies baked irradiance once; it does not also use the old decoded diffuse average. Warm point lights continue to illuminate baked meshes. Unassigned/unbaked surfaces retain Bevy ambient/sun lighting. Nonopaque surfaces retain the prior diffuse-average lightmap fallback.

All six retained faces of each assigned probe decode RGB/alpha into an unclipped linear RGBA16Float cube. `GeneratedEnvironmentMapLight` performs Bevy's GGX filtering and mip generation. The surface binds that probe's filtered specular map directly, preserving world/static assignments instead of approximating them with overlapping spatial volumes. Reflected directions transform back to the retained source Z-up cube basis; filtering preserves face order. Gloss selects a roughness-dependent mip, and Bevy's `F_AB` split-sum BRDF supplies reflection weighting. Reflection is added once in scene-linear space before Bevy fog/post-light processing. We do not install a second render pipeline or camera environment diffuse source.

Source-relative lightmap/SH/color radiance and cube radiance each use a shared 64 cd/m² calibration. This replaces additive ambient fill on baked opaque surfaces and preserves visibility with the existing exposure. It is a practical exposure-unit reconstruction, not native HDR scale recovery. Native view-dependent reflection modulation, geometric-lightmap/SH reflection normalization, exact gloss-to-lobe conversion and original compressed mip chains remain approximate.

Color textures use Bevy's sRGB decoding; normal/specular/control/lightmap/cube channels use linear data views. Retained vertex colors keep the preparation's linear convention. WGSL outputs scene-linear HDR once; AgX, bloom, exposure and display transfer remain Bevy responsibilities. We do not reproduce the native shader's intermediate square-root output or square albedo again.

Placed `glass_on` surfaces retain warm emissive glass and Bevy point lights at their bounds. Emissive glass avoids self-shadowing; lantern shadows enable within ten meters of the camera. Cool fog, sunlight and the compact HUD remain. Exposure still transitions between indoor EV100 7 and outdoor EV100 9.7 using an upward Avian cover ray, rather than recovered authored exposure volumes.

## Fidelity and validation

The render root stays hidden during material/lightmap assembly, then Bevy visibility reveals it when opaque assignments are ready; this avoids transient stale lightmap pipeline layouts during startup. The opt-in real-window driver records opaque coverage and pending assignment counts, traverses gameplay and sweeps position/yaw at eight survey views. Compiler gates do not validate WGSL; actual-window pipeline logs and inspected screenshots are necessary. Asset closure checks establish retention/integrity, never original equivalence. Current evidence and actual failures are in the single current handoff.

This milestone is APPROXIMATE. General layered terrain/control evaluation, cutout/transparency defects, water, atmosphere redesign, remaining helper/debug-colored surfaces, per-vertex static lighting, source fog/HDR constants and complete original equivalence remain outside scope. Existing malformed vegetation/helper-like shapes remain visible in outdoor surveys. The temporary pistol remains temporary.
